FILEFLOW DEPLOYMENT GUIDE

1) Local Development
- Run: pip install -r requirements.txt
- Run: streamlit run app.py
- View: http://localhost:8501

2) Deploy to Render (Free Cloud Hosting)
Method A (Automated Blueprint):
- Visit https://dashboard.render.com
- Click "New +" -> "Blueprint"
- Connect your GitHub repository: tejalselokar25/Experiential-Learning-Python
- Render will detect render.yaml and auto-configure all settings.
- Click "Apply" to deploy.

Method B (Manual Web Service):
- Visit https://dashboard.render.com
- Click "New +" -> "Web Service"
- Connect repo: tejalselokar25/Experiential-Learning-Python
- Root Directory: FileFlow
- Runtime: Python 3
- Build Command: pip install --upgrade pip && pip install -r requirements.txt
- Start Command: streamlit run app.py --server.port $PORT --server.address 0.0.0.0 --server.headless true
- Plan: Free
- Click "Create Web Service"

3) Deploy to Streamlit Community Cloud
- Direct 1-Click Link: https://share.streamlit.io/deploy?repository=tejalselokar25/Experiential-Learning-Python&branch=main&main_module=FileFlow/app.py
- Sign in with GitHub and click Deploy.

4) Deploy to GitHub Pages (Static Preview)
- Open https://github.com/tejalselokar25/Experiential-Learning-Python/settings/pages
- Under Branch, select main and /(root), then Save.
